## 3. 경기 동기화 (보병) — 처음엔 방장도 메인 스레드
- [ ] Game에 네트워크 역할(혼자 / 방장 / 참가자) 넣기
- [ ] 참가자: 입력 번호 붙여 보내기, 내 병사 예측 + 보정

- [ ] 스냅샷 20~30 Hz(병사 위치·자세·체력), 관심 범위, 보간 100 ms
- [ ] 이벤트: 처치, 다운/부활, 점령, 모드, 경기 끝
- [ ] 사격 판정은 방장, 지연 보상(히트박스 1초 기록 되감기)
- [ ] 참가자 화면: 원격 병사 모델, 총구 화염, 소리
- [ ] 중간 참가(전체 상태)
