- [x] 수류탄: 서버가 던지고 굴려 터뜨림(파편은 서버가 피해 판정), 브라우저는 날아가는 수류탄을 스냅샷으로 그리고(새 `things` 칸) 폭발은 그 시점에 맞춰 보여 줌; 섬광은 각자 보는 방향으로, 연막은 각자 그림
- [x] 의무병 구급상자·지원병 탄약 건네기(사람끼리, E): 필요한 사람은 스냅샷 표시(`SF.needMedkit/needAmmo`)로 안내
- [x] 가젯, 건설, 보급소: 공통 코드 `src/sim/kit.ts`(서버가 실제로, 브라우저는 같은 코드로 예측). 건설 자리는 양쪽이 같은 계산으로 만들어 id가 같음(`fortPlanFor`), 상태는 `mstate.fort`로; 로켓·소총 연막·비콘·지뢰는 스냅샷 `things`로 그림, 폭발은 시점 맞춰 표시; 비콘 배치는 같은 편 누구나(분대가 아직 없어서)
- [x] 차량·비행기(2026-10-05): 사람이 운전하는 차량은 그 사람 브라우저가 직접 몰고 입력 프레임 끝에 위치·회전·속도를 붙여 보냄(`encodeInputsDrive`), 서버는 차량 최고 속도의 1.6배 + 3 m보다 멀리 가면 거부하고(로그에 `suspect`) 아니면 자기 차량을 그 자리로(키네마틱). 빈 차량·봇 운전·모든 차량 총은 서버가. 타기·내리기·자리 바꾸기는 서버가 정하고 `seat` 이벤트로 알림. 스냅샷 끝에 차량(21바이트 + 자리마다 5바이트: 탑승자, 총 방향, 발사 수), 브라우저는 서버 차량의 복사본을 같은 배치(`vehicleWorldFor`)로 만들어 보간해 그림(키네마틱이라 부딪힘). 배치 화면의 전차·전투기·빈자리 탑승, 전투기 탈출 낙하산(`Soldier.stepChute`, 양쪽 같은 계산), 봇의 전차·전투기, 봇 탑승은 혼자 할 때와 같음
- [x] 분대: 서버가 편마다 4명씩 들어온 순서로 묶음(첫 사람이 분대장), 분대원 옆 배치, 분대 전멸 시 +5초, 비콘은 분대만
- [x] 콜인: 분대장만(B 메뉴, 서버가 RP·쿨다운 판정), 포탄·연막은 서버 폭발로, 정찰기·보급상자·표시 기둥은 서버가 알린 호출을 브라우저가 따라 그림, 정찰기에 찍힌 적은 그 편 미니맵에, 보급상자는 서버가 나눠 줌. 로켓 전차는 차량이 서버에 들어올 때
- [x] 봇을 서버가 돌림(유저+빈자리 봇, 협동 vs 봇): 방 크기만큼 양쪽을 봇으로 채우고 사람이 들어오면 그 편 봇 하나가 빠짐(분대 자리 그대로), 나가면 돌아옴; 사람과 가장 가까운 거리 기준 LOD; navmesh는 서버 디스크의 구운 파일
- [x] 봇 계산 분산(2026-10-05, 방 설정 "봇 계산 나눠 맡기"): 사람이 있는 분대의 봇(살아 있고 차량 밖)을 그 분대 사람의 데스크톱 브라우저 하나가 맡음(1초마다 배정, 한 브라우저 최대 8명). 브라우저는 혼자 할 때와 같은 `BotManager`로 그 봇들을 돌리고(navmesh는 구운 파일), 입력 프레임 끝에 봇 위치·조준과 한 일(방아쇠, 수류탄, 부활, 구급상자)을 붙여 보냄. 서버는 이동 속도를 검사해 자기 봇을 그 자리로 옮기고(`Bot.puppet`), 사격은 탄 퍼짐을 서버가 붙이고 그 브라우저가 본 틱으로 되감아 판정, 연사 속도·투척 간격·부활 거리 검사. 쓰러지거나 죽거나 차량에 타거나 브라우저가 1초 넘게 조용하면(탭이 백그라운드) 서버가 다시 맡음. 맡긴 봇은 가젯·건설·차량은 하지 않음(서버가 맡은 봇만). 노트북 실측(사람 4명, 60초): 아르덴 봇 64명 틱당 4.5 ms, 128명 6.7 ms, 철문 32명 3.3 ms
- [x] 차량·비행기·로켓 전차를 서버로 (로켓 전차: 분대장 콜인, 서버가 가까운 거점 옆에 내고 그 편에 알림)
