# 유튜브 쇼츠

## 올릴 때마다 쓰는 문구

쇼츠의 설명란과 댓글 링크는 눌리지 않으므로, 주소는 직접 칠 수 있게 그대로 적는다.

### 설명란

```text
Strikegy - AI로 직접 개발한 브라우저 FPS

설치 없이 무료, PC와 모바일 모두 플레이 가능
주소창에 strikegy.xyz

봇전은 가입 없이 바로, 멀티플레이는 로그인 후 가능

Free browser FPS. No install, PC and mobile.

#shorts #FPS #인디게임
```

### 고정 댓글

```text
게임 이름은 Strikegy예요. 주소창에 strikegy.xyz 치면 설치 없이 바로 됩니다. 무료예요.
```

### 업로드 설정

- **관련 동영상:** [트레일러](https://youtu.be/7Oie1ex3wS8)를 지정한다. 쇼츠 화면에서 눌리는 링크가 된다.
- **채널 프로필:** 인증이 끝났다면 게임 링크를 넣어 둔다.

## 영상 만들기

16:9 게임 클립을 1080x1920 세로 화면 가운데에 넣는다. 위에는 제목, 아래에는 게임 이름과 주소가 들어간다.

```bash
node scripts/shorts/build.mjs <클립 경로> --title "제목" --from 2 --to 11 --out 파일이름
```

- 결과물은 git에 올라가지 않는 `assets-src/shorts/`에 저장된다.
- 제목에 `\n`을 넣으면 줄이 바뀐다. `--sub`로 작은 부제를, `--still 3`으로 3초 지점의 미리보기 사진을 만들 수 있다.
- 브라우저 창째로 녹화된 클립은 `--crop 36,4`처럼 위아래를 잘라 제목줄을 없앤다(앱 창 기준 위 36픽셀, 아래 4픽셀). 게임 화면 높이는 자른 비율에 맞춰 자동으로 바뀐다.
- Medal 클립의 오디오 트랙은 4개이며 그중 첫 번째를 쓴다. 지금까지 본 클립은 앞의 2개에만 소리가 있었다. 마이크를 켜고 녹음했다면 올리기 전에 들어 본다.

## 방향 (주인, 2026-11-01)

- 실제 플레이에서 나온 어이없는 장면 하나에 건조한 제목을 붙이는 형식이 맞다. 각본을 짠 농담은 재미없었다.
- 설명 자막과 음악은 넣지 않고 게임 소리를 살린다.
- 재미의 핵심 장면이 끝나면 바로 자른다.
