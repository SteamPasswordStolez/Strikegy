# 지형지물 그래픽 리워크 기획 (오너 2026-10-26, 출시 준비)

오너 답변(2026-10-26):
- 범위: **땅 표면 · 자연물 · 인공 지형지물 · 건물 외관 전부**, 특히 **각진(마인크래프트 같은) 부분**이 B급 게임 느낌을 주니 그것부터.
- 방식: **스캔 모델까지** 사용(다운로드는 목록 승인 후).
- 성능: **오너 노트북(MX450) 60fps** 유지. 화질을 낮추지 않는 규칙, 삼각형이 늘면 전후 ms를 재고 비용이 늘면 최적화로 메우는 규칙은 그대로.
- 시작: **모든 맵이 같이 쓰는 공용 부품 + 가장 각진 부품**부터.

## 1. 지금 상태 (2026-10-26 조사)

맵 JSON의 `objects` 중 키트가 아닌 것은 `buildBlockout.addBox`가 **모서리 날카로운 정육면체**(`BoxGeometry`)로 그린다. 이게 각진 느낌의 주범이다.

|---|---|---|
| 철문 주둔지 | 505 / 303 / 193 / 112 | 아스팔트·자갈 바닥, 콘크리트 낮은 벽(0.5×1.3×4.5 m 56개), 벽돌 벽, 철로 레일(얇은 금속 띠 74개) |
| 아르덴 | 555 / 456 / 190 / 218 | 콘크리트 엄폐 291, 바위 벽 30, 나무 엄폐 39 |
| 리옹 | 477 / 461 / 83 / 0 | 콘크리트 245, **풀 엄폐(생울타리) 121**, 돌담 |

| 페르시아 | 117 / 80 / 107 / 0 | **흙벽(모래 재질) 70**, 바위 벽 18 |

화면에서 확인한 것(철문 주둔지, GPU 창): 운하 벽 같은 큰 콘크리트 판, 질감만 입힌 상자인 헤스코, 비탈에서 판처럼 꺾이는 자갈 바닥(돌 무늬도 너무 큼), 판판한 벽 윗면.

키트(`modelKits.ts`: 차, 모래주머니, 컨테이너, 망루, 헤스코, 트럭, 벤치 …)는 지난 소품 패스에서 모양을 갖췄지만 헤스코처럼 아직 상자에 가까운 것이 남아 있다. 나무는 절차 생성(`treeSpecies.ts`), 바위·덤불 일부는 이미 Poly Haven 스캔(`rock_moss_set`, `shrub_02/04`, `fern_02`, `tree_stump_01`, `dead_tree_trunk`).

## 2. 원칙

- **충돌체는 그대로 상자**(서버·봇·내비 메시와 같아야 하고, 맵 JSON도 그대로). 바뀌는 건 보이는 모양뿐.
- 맨 상자를 **문맥별 모양**으로 바꾼다: 재질 + 크기 + 종류로 무엇인지 알아보고(예: 콘크리트 0.5×1.3×L = 낮은 벽) 그에 맞는 모델로 그린다. 맵 스크립트는 고치지 않는다.
- 스캔 모델은 **meshoptimizer로 LOD 3단계**(가까이 / 중간 / 멀리), 텍스처는 1K를 webp로, 같은 모델은 **인스턴싱**. 이미 쓰는 소품 파이프라인(`scripts/optimize-assets.mjs`)에 붙인다.
- 각 단계마다 GPU 창에서 같은 시점의 전후 ms(타이머 쿼리)를 재고, 늘면 메운다.

## 3. 단계

### 1단계 — 공용 부품, 가장 각진 것
1. **콘크리트 낮은 벽 / 블록**: 모서리 깎기(베벨), 아래 넓은 저지 방호벽 단면, 깨진 모서리와 철근, 이음매. 스캔 `concrete_road_barrier_02`(이미 1번은 있음)를 길이에 맞춰 반복 배치.
2. **벽돌·돌담**: 갓돌(위 덮개), 줄눈이 보이는 질감, 윗부분이 군데군데 무너진 모양, 끝 기둥.
3. **바위 벽**: 상자를 스캔 바위 여러 개로 덮기(`boulder_01`, `namaqualand_boulder_02/04`, `rock_07/09`), 크기를 맞춰 겹쳐 쌓음.
4. **생울타리(리옹 풀 엄폐)**: 둥근 덩어리 + 잎 카드, 바닥 가지.
5. **흙벽(페르시아)**: 모서리가 둥글고 위가 깎여 나간 흙벽, 짚 섞인 흙 질감.
6. **나무 엄폐물**: 판자 울타리, 팔레트 더미, 통나무.
7. **철로 레일**: 레일 단면(I형), 침목, 자갈 도상.
8. **헤스코**: 철망 칸 + 불룩한 천 + 흙이 비치는 모양.
9. **바닥 판(도로·보도·광장)**: 지형과 섞이는 가장자리, 둥근 연석, 균열·얼룩·맨홀(스캔 `water_manhole_cover`) 무늬; 자갈 무늬 크기 바로잡기.

### 2단계 — 땅 표면
- 지형 질감에 맵별 스캔 세트 추가(흙길, 진흙, 낙엽, 자갈 — Poly Haven 텍스처, 별도 승인 목록).
- 지면 덮개 스캔: `moss_01`, `bark_debris_01`, `dry_branches_medium_01`, `pine_roots`, `root_cluster_01`(줄여서 인스턴스).
- 포탄 구덩이·바퀴 자국·물웅덩이 무늬, 건물 둘레의 잔해 띠.
- 풀: 스캔 풀(`grass_medium_01/02`)은 수십만~백만 폴리곤이라 그대로 못 씀 → 카드 텍스처로 구워 지금 풀 시스템에 사용.

### 3단계 — 자연물
- 바위·돌: 스캔 바위 전 맵 공용 세트.
- 덤불: `shrub_03`(1.6 MB, 1.7만 폴리곤) 추가.
- 쓰러진 나무: `dead_tree_trunk_02`.
- **나무는 Poly Haven 것이 너무 무거움**(전나무 487 MB, 소나무 958 MB, 소형 나무 101 MB). 지금 절차 나무를 고치고(줄기 굴곡, 가지 갈래, 잎 덩어리, 스캔 나무껍질 질감) 필요하면 오너가 Meshy로 만든 나무를 쓰는 방법을 따로 제안.

### 4단계 — 건물 외관 (오너 순서의 (c))
- 창틀·창턱·처마·발코니·문, 지붕 장비.
- 스캔 부품: 배수관 `modular_metal_gutter`, 셔터 `rollershutter_door`, 비상계단 `modular_fire_escape`, 배전함 `utility_box_01/02`, 소화전 `fire_hydrant`, 전신주 `modular_electricity_poles`, 철망 울타리 `modular_chainlink_fence`.

## 6. 진행 상황

### 2026-10-26 — 1단계 일부 (승인 다운로드 + 맨 상자 다듬기 + 스캔 바위)
- 다운로드(승인): 8개 중 7개 사용. `boulder_01`은 줄이기가 안 돼(약 5.6만 삼각형) 뺐다. 게임용 합계 약 1.9 MB.
- `src/world/boxDress.ts`: 키트가 아닌 맵 상자를 재질·모양별로 다르게 그림 (충돌·내비·서버는 그대로, 35 m 너머 칸은 원래 상자).
  - 콘크리트·금속·나무: 모서리 깎기
  - 벽돌·회벽: 모서리 깎기 + 긴 벽 윗선이 군데군데 무너짐
  - 흙벽: 둥근 모서리, 윗면 깎임
  - 생울타리: 둥글고 울퉁불퉁한 덩어리 (잎 카드는 2단계)
  - 바위: 울퉁불퉁한 심
  - 배관(단면이 정사각에 가깝고 긴 금속): 원통
  - 철로 띠: 레일 단면
  - 0.5 m 이상 높은 바닥 판만 모서리 깎기 (얇은 도로 판은 삼각형만 늘어서 제외)
- `src/world/scanDress.ts`: 바위 벽 위에 스캔 큰 바위(맵 바위 색으로 물들임), 발치에 잔돌, 넓은 아스팔트에 맨홀. 모델당 인스턴스 메시 하나에 카메라 근처 것만 채움(큰 바위 65 m, 잔돌 35 m, 맨홀 40 m), 그림자는 받기만, 바위 심보다 먼저 그림.
- 개발용 `?nodress`(원래 상자), 측정은 한 페이지 안에서 프레임마다 켬/끔을 번갈아(`public/__bench/views.js`, 커밋 안 함).
- 측정(이 PC Iris Xe, 1152x648, 같은 화면 번갈아): 철문 주둔지·리옹·페르시아 대부분 시점 잡음 범위(±0.1 ms 안팎), **아르덴 바위 바로 앞 시점 평균 약 +0.26 ms** (처음 +0.5~0.7에서 줄임; 스캔 바위가 70만 삼각형이던 것을 잡은 뒤). 남은 비용은 스캔 바위가 화면을 크게 덮는 근접 시점의 화소 계산으로 보임 — 다음에 바위 텍스처 크기와 바위 심 축소로 더 줄인다.
- 남은 1단계: 헤스코, 콘크리트 낮은 벽의 스캔 방호벽(`concrete_road_barrier_02`, 받아 둠·아직 안 씀), 남은 비용 줄이기.
