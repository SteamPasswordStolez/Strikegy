# 정식 출시 준비 (오너 2026-10-26)

## 정해진 것 (오너)
- **서비스 방식: 웹**(strikegy.xyz, 앱 설치형 PWA 포함). 스팀은 지금은 아님.
- **판매: 보급표.** 보급표를 그냥 사는 것은 효율이 일부러 나쁘게(단가 높게) 하고, **기간 한정으로 뜨는 패키지와 배틀패스**를 주력으로 판다.
- **안티치트는 반드시** 한다(멀티 순서의 마지막 단계).
- **보안 취약점 검사는 나중에 한 번에** 전체를 돌린다.
- **모바일 조작성 점검**이 필요하다.
- 출시 준비 1(가격·수급 조정)은 끝남: income.ts `INCOME = 1/4`, 가격 인상 (CLAUDE.md "Launch preparation 1").
- 지형지물 그래픽 리워크 진행 중: props-rework.md.
