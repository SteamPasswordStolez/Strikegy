# 성장 요소 기획: 계정과 "계속할 이유" (2026-10-19, 초안)

오너(2026-10-19): "뭔가 성장요소(계정, 게임을 계속할 이유)가 필요한 거 같은데.. 기획만 어느 정도 해서 문서로만 남기자 (여기선 서버를 못 건드려서 로컬에서 몰아서 하는 게 나을 거 같음)."

이 문서는 **기획만** 한다. 만드는 건 오너 PC의 로컬 세션에서 한 번에 한다(서버 저장소와 노트북 업데이트가 같이 필요해서). [제안]은 Claude의 제안이고 오너가 정하면 [확정]으로 바꾼다. 맨 끝 10절에 오너가 답할 질문을 모았다.

참고: 2026-10-04에 메인 메뉴의 "계급 / XP 카드"를 만들었다가 오너 요청으로 뺐다. 그때는 실제로 쌓이는 게 없는 장식이었다. 이번 기획은 실제 진행(해금, 기록, 도전)이 먼저고 메뉴에 보이는 건 그 결과다.

## 1. 지금 상태

- **계정이 없다.** 브라우저마다 숨은 ID(`strikegy.player.v1`의 `uid`, 24자리 16진수)와 이름만 있다. 멀티에서는 서버가 이 ID로 `이름#TAG`를 만든다(`tagOf`). 브라우저 저장소를 지우거나 기기를 바꾸면 다른 사람이 된다.
- **쌓이는 게 없다.** 경기 점수(`ScoreTracker`: 처치 100, 헤드샷 +25, 점령 150, 무력화 75, 소생 100/150, 보급 20)는 경기가 끝나면 사라진다. 병과별 장비 선택(`strikegy.loadouts.v1`)만 남는다.
- **처음부터 다 열려 있다.** 무기 23정(돌격소총 4, 기관단총 4, 경기관총 3, 산탄총 3, 지정사수 3, 저격 3, 권총 3), 병과 4개, 가젯, 지원 요청 전부.
- **부착물이 없다.** 조준경·소음기·손잡이는 무기마다 정해진 모양이다(`optics.ts`, `LOOKS` in gunModels). 모양은 이미 여러 종류가 코드로 있다(레드닷, 홀로, 리플렉스, 프리즘, 배율 조준경 5종, 소음기, 제퇴기, 수직·경사 손잡이, 전술등, 양각대).
- 사람들은 **봇전(솔로)**을 많이 한다. 멀티는 노트북 서버 한 대.

## 2. 목표와 원칙

**목표**: 한 판 끝나면 "뭔가 늘었다"가 보이고, 다음 판에 할 일이 있고, 오래 하면 보여 줄 것이 생긴다. CoD MW(오너가 더 참고하라고 한 쪽)의 무기 레벨·부착물·위장 도전과, BFV의 병과 숙련·임무를 섞는다.

**원칙** [제안]
1. **해금은 옆으로(사이드그레이드), 위로는 아니다.** 오래 한 사람이 더 센 총을 갖지 않는다. 새 무기와 부착물은 "다른 선택"이지 "더 좋은 선택"이 아니다. 지금의 무기 밸런스(TTK 표, `gunplay-audit.md`)는 그대로 둔다.
2. **처음 한 시간 안에 기본은 다 열린다.** 새로 온 사람이 잠긴 것만 보고 떠나지 않게, 병과마다 무기 종류별로 하나씩은 처음부터 열려 있다.
3. **보여 줄 것은 꾸밈이다.** 위장 무늬, 카드, 엠블럼, 계급장. 피아 구분은 절대 흐리지 않는다(우리 편 파랑 계열, 적 빨강 계열 군복·마커는 그대로). 꾸밈은 무기, 이름표, 프로필에만.
4. **돈은 없다.** 유료 아이템, 랜덤 박스 없음. 시즌 보상도 무료.
5. **개인정보는 받지 않는다.** 이메일, 비밀번호, 실명 없이 시작한다(4절).
6. **다운로드 없이.** 위장 무늬, 엠블럼, 카드는 셰이더와 캔버스로 절차적으로 만든다(차량 위장이 이미 셰이더로 된다).

## 3. 진행 축

### 3-1. 계급 (플레이어 레벨)

- **경험치(XP) = 경기 점수** + 경기 완료 보너스 + 승리 보너스 + 리본(3-6절). 이미 있는 점수표를 그대로 쓰니, 점령·소생·보급처럼 팀에 도움 되는 행동이 처치만큼 XP가 된다.
- 계급 1-50, 50 이후 **복무 기장**(프레스티지 대신): 50에서 다시 1로 내려가지 않고, 기장 별을 하나 받고 계속 쌓는다(CoD처럼 해금을 잃지 않는다). [제안]
- 곡선 [제안]: 다음 계급까지 `2,000 + 400 × (계급 − 1)` XP. 1→50 합계 약 57만 XP.
- 속도 추정(봇전 실측 아님, 만들 때 `bots:pace`처럼 재 본다): 10분 경기에서 사람 점수 2,000-3,000 + 완료 500 + 승리 500 → 한 판 약 3,000, 한 시간 약 18,000-20,000 XP. **50까지 약 30시간**. CoD의 첫 프레스티지와 비슷하게 잡았다.
- 계급이 여는 것: 무기(3-3), 지원 요청 일부, 카드·엠블럼. 계급장은 이름 옆과 점수판에 작은 아이콘으로.

### 3-2. 병과 숙련 (BFV식)

- 병과(돌격·의무·지원·정찰)마다 1-10. 그 병과로 번 XP가 쌓인다.
- 여는 것 [제안]: 병과 가젯의 변형(아래), 병과 전용 꾸밈(헬멧 커버, 견장, 카드), 10에서 병과 "베테랑" 휘장.
- 가젯 변형 후보(새로 만들어야 함, 밸런스는 옆으로): 돌격 — 판저파우스트 / 대전차 지뢰 2개; 의무 — 소총 연막 / 구급 상자 던지기; 지원 — 탄약 가방 / 박격포 소형(분대 지원 요청과 겹치면 뺀다); 정찰 — 비컨 / 지뢰(이미 있음) / 동작 감지기. **지금 있는 가젯은 처음부터 열려 있고**, 숙련은 대안만 연다.

### 3-3. 무기 해금

- [제안] 처음부터 열림: 병과마다 쓸 수 있는 무기 종류별로 하나씩 (돌격소총 M4A1, 기관단총 MP7, 경기관총 M249, 산탄총 M590, 지정사수 Mk 12 SPR, 저격 M24, 권총 M9). 7정.
- 나머지 16정은 계급 2-16에 하나씩, **약 5-6시간 안에 전부**. 오래 잠가 두지 않는다.
- 다른 길: "무기 종류 숙련" — 같은 종류의 총으로 처치 N이면 다음 총이 열린다(BF4 방식). 계급과 둘 중 먼저 오는 쪽으로 열리게 하면 좋아하는 종류만 하는 사람도 막히지 않는다. [제안: 둘 다]
- 방 설정 **"전부 해금"**(멀티 방, 솔로 설정 둘 다): 이벤트, 친구끼리, 처음 온 친구를 데려왔을 때. 기본값은 켜짐? 꺼짐? → 10절 질문.

### 3-4. 무기 레벨과 부착물 (CoD MW식, 가장 큰 일)

이게 "계속할 이유"의 중심이다. 좋아하는 총을 계속 쓰면 그 총이 내 것이 된다.

- 무기마다 레벨 1-20. 그 총으로 번 점수(처치, 그 총으로 한 어시스트)가 무기 XP. 레벨당 1,000 → 한 정당 약 1.5-2시간.
- **부착물 시스템을 새로 만든다.** 슬롯 5개 [제안]: 조준경 / 총구 / 하부(손잡이·양각대) / 탄창 / 레이저·전술등. 하나의 총에 슬롯마다 2-4개, 레벨 2-20에 걸쳐 열린다.
- 부착물은 **장단점이 함께** 있다(CoD MW처럼). 예:
  - 조준경: 배율·시야 가림 ↔ 조준 속도(`adsTime`). 레드닷/홀로/리플렉스/프리즘은 모양만 다른 1배율(취향).
  - 소음기: 미니맵에 안 뜸, 봇이 듣는 거리 70 → 22 m(MP5SD에 이미 있는 규칙) ↔ 조준 속도·이동 속도 조금 손해, 사거리 감쇠(`FALLOFF`) 조금 짧게.
  - 제퇴기: 수직 반동 −10 % ↔ 소리 더 크게(적이 더 멀리서 들음), 조준 속도 손해.
  - 수직 손잡이: 수직 반동 −8 % ↔ 조준 속도 손해. 경사 손잡이: 조준 속도 + ↔ 반동 +.
  - 확장 탄창: 탄 +50 % ↔ 재장전·조준 속도 손해.
  - 레이저: 지향 사격 퍼짐 −20 % ↔ 적에게 빛이 보임.
- 숫자는 `weaponData.ts`의 `kick` / `recoil` / `adsTime` / `sprintOut` / `FALLOFF`에 곱하는 배수로만 둔다(새 무기를 만드는 게 아님). 한 총에서 아무리 조합해도 TTK는 그대로(피해량은 안 바꾼다).
- 모델: `buildGun`이 부착물 목록을 받아 붙인다. 지금은 `LOOKS`가 무기마다 고정이니, 그걸 "기본 부착물"로 바꾸는 일. 1인칭 모델(`full`)과 봇 모델(`low`) 둘 다. **삼각형이 늘면 ms 측정 규칙**(CLAUDE.md) 대상.
- 네트워크: 부착물은 배치할 때 장비 정보에 실려 간다(`deploy`의 loadout). 서버가 그 사람이 정말 열었는지 계정으로 확인한다(4절). 서버의 판정(퍼짐, 반동 회복)도 같은 배수를 쓴다 → 프로토콜 버전 올림.
- 봇: 열린 것 중에서 성격대로 고른다(저격형은 배율, 돌격형은 1배율).

### 3-5. 위장 무늬 (도전으로 얻는 꾸밈)

- 무기마다 도전 단계 [제안]: 처치 50 / 헤드샷 25 / 처치 150 / 한 목숨에 3킬 5번 / 원거리 처치(무기 종류별 거리) 10 → 단계마다 무늬 하나.
- 한 총의 단계를 다 끝내면 그 총의 **황동** 무늬, 한 종류(예: 돌격소총 4정)를 다 황동으로 만들면 **흑요석**, 전 무기 흑요석이면 최종 무늬(이름 미정). CoD의 골드 → 다마스커스 흐름이지만 이름·모양은 우리 것.
- 무늬는 셰이더로: 숲, 사막, 도시, 호랑이 줄무늬, 디지털, 황동(금속감), 흑요석(검은 광택 + 결). 차량 위장 셰이더(`vehicleLooks.ts`)와 같은 방식. 3인칭 봇 총에도 보이면 좋지만 먼 거리에서는 기본색(성능).

### 3-6. 리본과 경기 안 보상 (BFV식)

- 한 경기 안에서 반복되는 행동에 리본: 처치 4번, 소생 4번, 보급 4번, 점령 2번, 차량 파괴 1번, 분대원 근처 처치(분대 플레이) … 받을 때마다 XP +250, 화면 가운데 작은 알림(`HUD.scorePopup` 옆).
- 연속 처치 보상(CoD의 킬스트릭)은 **넣지 않는다** [제안]: 분대 지원 요청(RP)이 이미 그 역할을 하고, 팀 플레이를 해친다.

### 3-7. 임무 (도전 과제)

- **일일 3개 / 주간 6개**, 무작위(그날 할 만한 것): "의무병으로 소생 10", "산호 해역에서 함선 피해 5만", "헤드샷 15", "점령 5" … 보상은 XP와 가끔 꾸밈.
- **상시 임무**(BFV의 과제): 해금과 묶인 긴 목표. 예: "정찰로 비컨 배치 50 → 비컨 꾸밈", "전차로 처치 100 → 전차 위장 무늬". 차량 숙련(전차, 전투기, 함선, 함재기)도 여기로.
- 임무 진행은 경기 중 이벤트(`combat:kill`, `zone:captured`, 소생, 보급, `mode:event`, 바다 피해)로 센다 → 3-9의 진행 기록기 하나에서.

### 3-8. 병적부 (기록 페이지)

- 메인 메뉴의 이름 카드 → **병적부**: 계급·기장, 병과 숙련, 무기별 레벨과 처치, 전체 기록(처치, 죽음, K/D, 명중률, 헤드샷률, 소생, 점령, 플레이 시간 병과·맵·모드·차량별, 최고 점수 경기), 최근 20경기(맵, 모드, 결과, 점수, 처치/죽음).
- 결과 화면(`Overlay.setResult`)에: XP 막대가 차오르는 연출, 계급·무기 레벨 오름, 새로 열린 것 카드, 임무 진행. CoD의 경기 후 화면.
- 이름표 `이름#TAG` 옆 계급장 아이콘(점수판, 대기실, 채팅).

### 3-9. 시즌 (나중)

- 6-8주마다 "작전 기록"(무료 시즌 진행도 50단계, 꾸밈만). 지도, 모드, 무기 추가와 맞춰 낸다. 사람이 적을 때는 의미가 작아서 **마지막 단계**로 미룬다.

## 4. 계정

### 4-1. 단계

1. **로컬 프로필**(브라우저 저장소): 진행 전부를 브라우저에 저장. 솔로만 하는 사람도 바로 쓴다. 서버 없이 만들 수 있다.
2. **서버 계정**: 게임 서버가 진행을 갖고 있고, 브라우저는 사본만. 서버가 보는 경기(멀티)는 서버가 직접 계산한다.
3. **기기 옮기기**: 비밀번호 없이 **이전 코드**. 병적부에서 "이전 코드 만들기" → 16자 코드(10분 유효, 한 번만) → 다른 기기에서 입력하면 그 기기의 숨은 ID가 같은 계정에 묶인다. 잃어버렸을 때 되찾는 길은 없다(개인정보를 안 받으니까) → 병적부에서 "복구 코드"(영구, 한 번 보여 줌)를 적어 두게 한다. [제안]
4. (나중, 오너 결정) 구글·디스코드 로그인: 도메인(strikegy.xyz)과 OAuth 앱 등록이 필요하고, 개인정보 처리 안내가 필요해진다. 사람이 많아지면.

### 4-2. 솔로 진행을 믿을 수 있나

- 솔로(봇전)는 브라우저가 계산한다 → 저장소를 고치면 속일 수 있다. 피해는 **자기 꾸밈과 해금뿐**(남과 겨루지 않는 것)이라 막는 데 큰 비용을 쓰지 않는다. [제안]
  - 서버 계정에 솔로 결과를 올릴 때 **상식 검사**: 경기 길이 대비 점수 상한, 처치/분 상한(봇 수·난이도·모드로), 하루 솔로 XP 상한(예: 20만). 넘으면 잘라서 받는다.
  - **순위표**(나중)는 서버 경기 기록만.
- 서버 경기(멀티)는 서버의 점수표로 계산하니 믿을 수 있다. 서버가 경기 끝에 사람마다 요약을 만들어 계정에 더하고 `{t:'progress', ...}`로 알려 준다.

### 4-3. 저장

- 노트북 서버(Node 20, 업그레이드 금지): `node:sqlite`는 Node 22부터라 못 쓴다. [제안] **`better-sqlite3`**(Node 20용 미리 빌드된 바이너리가 있다, 서버 의존성 하나 추가) 또는 지금 관리자 저장소(`AdminStore`, JSON 한 파일)처럼 **계정당 JSON 파일 + 원자적 쓰기**. 사람이 수백 명 수준이면 JSON으로 충분하고 의존성이 없다 → JSON으로 시작, 커지면 SQLite.
- 계정 키 = 서버만 아는 키로 만든 HMAC(숨은 ID) — 태그와 같은 방식. 파일에는 숨은 ID를 그대로 쓰지 않는다.
- 백업: 하루 한 번 파일 묶음을 압축(노트북 cron). 관리자 페이지(`/admin/`)에 계정 찾기(이름#TAG), 진행 보기, 초기화(핵 의심), 이전 코드 무효화.

### 4-4. 데이터 모양 [제안]

```ts
interface Profile {
  v: 1;
  xp: number;                 // 총 XP (계급과 기장은 여기서 계산)
  classXp: Record<ClassId, number>;
  weapons: Record<WeaponId, { xp: number; kills: number; headshots: number; longshots: number; streaks3: number; camos: number }>;
  vehicles: Record<string, { kills: number; time: number }>;
  unlocks: string[];          // 'weapon:ar2', 'att:ar1:suppressor', 'camo:ar1:tiger', 'card:...'
  equipped: { card?: string; emblem?: string; camo: Partial<Record<WeaponId, string>>; attachments: Partial<Record<WeaponId, Partial<Record<Slot, string>>>> };
  missions: { daily: MissionState[]; weekly: MissionState[]; long: Record<string, number>; rolledAt: number };
  stats: CareerStats;         // 3-8의 숫자들
  history: MatchRecord[];     // 최근 20
}
```

- 경기 안에서는 **진행 기록기**(`ProgressTracker`, 새 파일) 하나가 이벤트를 받아 `MatchSummary`(XP 항목별, 무기별 XP·처치, 리본, 임무 증가분)를 만든다. 솔로는 `Game`이, 멀티는 서버의 `MatchRoom`이 같은 코드를 돌린다(지금 `ScoreTracker`가 양쪽에서 도는 것처럼). 프로필에 더하는 함수도 하나(`applySummary`)로 양쪽이 같이 쓴다.

## 5. 숫자 정리 [제안]

| 항목 | 값 |
|---|---|
| XP | 경기 점수 1:1 + 완료 500 + 승리 500 + 리본 250씩 |
| 계급 | 1-50, 다음까지 2,000 + 400×(계급−1), 50 이후 기장(10만 XP마다 별 하나) |
| 무기 레벨 | 1-20, 레벨당 1,000 (그 총의 점수) |
| 병과 숙련 | 1-10, 레벨당 1만 (그 병과의 XP) |
| 처음 열린 무기 | 무기 종류별 1정씩 7정, 나머지 16정은 계급 2-16 |
| 일일 / 주간 임무 | 3개 각 2,000-4,000 XP / 6개 각 1만 XP |
| 솔로 XP 하루 상한 | 20만 (상식 검사용, 넘어도 기록은 남김) |

**예외가 필요한 곳**:
- **바다(산호 해역)**: 2026-10-18부터 바다에서는 준 피해가 그대로 점수다(5인치 한 발 1,400, 어뢰 20,000). 이걸 XP 1:1로 받으면 한 판에 수십만 XP가 나온다. → 바다 피해 점수는 **XP로 1/20**(어뢰 명중 1,000 XP, 처치 수준). [제안]
- **봇 난이도**: 쉬움 ×0.75, 보통 ×1, 어려움 ×1.25 [제안]. 봇 0명 연습·사격장은 XP 없음(튜토리얼 완료 보너스 1회만).
- **간소화 조작**: XP 그대로 [제안](폰에서 하는 사람을 벌주지 않음). 다만 간소화에서 못 하는 행동(소생, 보급)은 당연히 안 쌓인다.
- **긴 경기 / 큰 맵**(재의 섬 64v64, 산호 해역 30분): 완료 보너스를 경기 시간에 비례(10분당 500, 최대 1,500).

## 7. 멀티플레이와의 관계

- 배치할 때 보내는 장비에 부착물·위장이 실린다. 서버가 그 계정이 연 것인지 확인하고, 아니면 기본으로 바꾼다(안티치트). 방 설정 "전부 해금"이면 확인하지 않는다.
- 다른 사람에게 보이는 꾸밈(무기 위장, 계급장)은 스냅샷이 아니라 **참가할 때 한 번** 보낸다(사람 목록에 붙임). 봇 꾸밈은 서버가 정한다.
- 프로토콜 버전을 올린다(부착물이 판정에 들어가니까) → 노트북 업데이트 필요.
- 서버 경기 결과는 서버가 계정에 바로 더한다. 브라우저가 따로 보낼 것이 없다.

## 8. 만드는 순서 [제안] (로컬 세션에서)

1. **진행 기록기 + 로컬 프로필 + 계급**: `ProgressTracker`, `Profile`, 결과 화면 XP 연출, 병적부 기본, 메뉴 카드. 서버 없이 솔로에서 끝까지 확인 가능.
2. **서버 계정**: 계정 저장(JSON), 경기 끝 요약을 서버가 더함, 이전·복구 코드, 관리자 페이지에 계정. 노트북 업데이트.
3. **무기 해금 + 무기 레벨**: 잠금 표시, 방 설정 "전부 해금".
4. **부착물**: 슬롯·배수·모델·네트워크·봇. 가장 큰 일(밸런스 확인: TTK와 반동 측정, 사격장 수치). ms 측정.
5. **위장 무늬 + 리본 + 임무**.
6. **병과 숙련과 가젯 변형**(가젯 새로 만들기 포함).
7. (나중) 시즌, 순위표, 클랜 태그, 외부 로그인.

1-3까지가 "계속할 이유"의 뼈대고, 4가 CoD식 재미의 본체다.

## 9. 위험과 주의

- **밸런스**: 부착물이 TTK를 바꾸지 않게(피해량 손대지 않음). 반동·조준 속도 배수는 사격장 측정(`gunplay-audit.md`의 표)으로 확인.
- **새로 온 사람**: 무기를 잠그면 처음 몇 판이 단조로울 수 있다 → 처음 7정이 종류마다 하나씩이라 고를 거리는 있다. 튜토리얼 끝나면 보너스 XP로 계급 2-3까지.
- **봇전 농사**: 쉬운 봇 150명 방에서 XP 농사 → 난이도 배수와 봇 수 대비 처치 상한(상식 검사)으로 누그러뜨림. 막지는 않는다(자기 손해·자기 이득).
- **저장소 지움**: 로컬 프로필만 있는 사람은 브라우저 데이터를 지우면 진행이 사라진다 → 2단계(서버 계정) 전까지는 병적부에 "내보내기 / 가져오기"(파일) 버튼을 둔다.
- **서버 한 대**: 계정 파일이 노트북에만 있다 → 백업 필수(4-3).
- **성능**: 부착물·위장으로 총 모델이 무거워지면 1인칭은 괜찮아도 봇 수십 명의 3인칭 총이 문제 → 먼 거리는 지금처럼 단순 모델, 위장은 가까이서만.
