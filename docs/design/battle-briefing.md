# 전황 브리핑 (크리티컬 메시지) 설계 [제안]

오너 요청(2026-10-17): 배틀필드 V처럼 게임 중간중간 전황을 알려 주는 **음성 + 화면 메시지** 시스템. 음성은 오너가 ElevenLabs(OpenRouter)로 직접 만들고, 무전 느낌(대역 제한, 잡음)은 코드에서 입힌다.

[제안]은 아직 오너가 정하지 않은 것, [확정]은 정한 것.

---

## 1. 무엇을 만드나

- 판의 흐름이 바뀌는 순간에만 **우리 편 지휘부가 무전으로 짧게** 말한다. 거점을 얻거나 잃을 때, 섹터를 뚫거나 뚫릴 때, 이기거나 질 것 같을 때, 증원이 바닥날 때, 폭약이 설치될 때 등이다.
- 말과 함께 화면 위 가운데에 **크리티컬 메시지 띠**가 뜬다. 아이콘, 큰 한 줄, 작은 한 줄이다. 음성을 끄거나 파일이 없어도 글은 항상 나온다.
- 같은 사건이라도 **듣는 사람 편에 따라 말이 다르다.** 우리 편이 거점을 얻으면 "거점 브라보 확보.", 상대 편은 같은 순간에 "거점 브라보를 빼앗겼다!"를 듣는다. 플레이어는 늘 자기 편 지휘부 목소리만 듣는다.
- **수다스럽지 않게.** BFV도 큰 사건 때만 말한다. 아래 4장의 규칙으로 1분에 몇 번 이하로 묶는다.

## 2. 누가 말하나 [제안]

| 화자 | 언제 | 성격 |
|---|---|---|
| **지휘관 (HQ)** | 거의 모든 메시지 | 침착하고 단호한 중년 남성. 평소에는 낮게, 위급할 때 긴박하게 |
| **통신병** (2단계) | 위협 경보: 적 전투기, 적 전차, 포격 경보, 정찰기 | 빠르고 또렷한 목소리. 지휘관과 구별되게 다른 성별·톤 |
| **진행자** | 개인전, 건 게임, 최후의 1인 (편이 없는 모드) | 무전이 아닌 중립 진행 목소리 |

- 1단계는 지휘관 한 명이면 충분하다. 파란 편과 빨간 편 목소리를 따로 두면 생성할 양이 두 배가 되므로, 원하면 나중에 추가한다.

## 3. 언제 말하나: 큐 목록 [제안]

우선순위: **1 = 꼭 말함**(다른 말을 끊고서라도), **2 = 중요**(줄 서서 기다림), **3 = 정보**(한가할 때만, 오래 기다리면 버림).
쿨다운은 같은 큐를 다시 말하기까지 최소 시간이다. 대사의 "브라보"는 거점 글자를 군 음성 알파벳으로 읽은 것이다(자막은 "거점 B").

트리거는 모두 게임에 이미 있는 이벤트다: `zone:captured`, `zone:neutralized`, `mode:event`(sector / attack / time / refill / hill / charge / round / roundEnd / checkpoint / built / shrink / level), `match:ended`. 그리고 1초마다 보는 상태(점수 차, 목표 점수까지 남은 양, 티켓, 공격 남은 시간, 거점 소유, 장갑차 진행)다. 멀티플레이에서도 서버 이벤트가 같은 버스로 들어오므로 그대로 동작한다.

## 4. 수다 방지 규칙 [제안]

- **한 번에 하나.** 말하는 중이면 대기열에 넣는다. 우선 1은 우선 3을 끊고 바로 말한다(무전 끊기는 소리를 넣는다).
- **오래된 소식은 버린다.** 우선 1은 12초, 우선 2는 10초, 우선 3은 4초 넘게 기다리면 말하지 않는다.
- **간격.** 말이 끝나고 다음 말까지 최소 3초. 우선 1은 예외다.
- **분당 상한** 6회. 넘으면 우선 3은 건너뛴다.
- **뒤집힘 억제.** 같은 거점이 20초 안에 다시 넘어가면 두 번째는 띠만 띄우고 말하지 않는다.
- **같은 말 반복 금지.** 변형이 있으면 직전에 쓴 것을 빼고 고른다.
- **화면 상태.** 일시정지 중에는 멈춘다. 결과 화면에서는 end.win / end.lose만 말한다. 배치 화면에서는 말한다(BFV도 그렇다).

## 5. 화면: 크리티컬 메시지 띠 [제안]

- 위 가운데, 거점 배지 아래에 뜬다. 아이콘(거점 글자·폭약·전차 등), 큰 한 줄("거점 B 확보"), 작은 한 줄(필요할 때만, 예: "증원 25 % 남음")로 구성한다.
- 우리 편에 좋은 소식은 파란 띠, 나쁜 소식은 빨간 띠, 중립은 흰 띠. 3초간 보이고 0.3초에 걸쳐 사라진다.
- 지금 HUD의 `notify` 배너를 이 띠로 바꾼다. 같은 소식을 두 번 띄우지 않도록 브리핑이 띄우는 소식은 브리핑만 띄운다.
- 설정 "소리·언어"에 **음성 볼륨**(0~100 %)과 **자막**(켜기/끄기)을 넣는다. 띠는 자막을 꺼도 뜬다.

## 6. 무전 효과 (코드) [제안]

원본 음성 파일은 깨끗한 채로 두고, **재생할 때** Web Audio로 무전처럼 만든다. 원본을 두 번 만들 필요가 없고, 효과는 나중에 얼마든지 다시 맞출 수 있다.

```
음성 ─► 하이패스 320 Hz ─► 피킹 1.8 kHz +4 dB ─► 로우패스 3.2 kHz ─► 웨이브셰이퍼(살짝 찌그러짐)
     ─► 컴프레서(빠르게, 6:1) ─► 음성 버스 ─► 마스터
잡음 ─► 밴드패스 2 kHz (Q 0.7) ─► 아주 작게, 천천히 흔들리게 ─┘   (말 0.12초 전부터 0.15초 후까지)
```

- **키 소리**: 말 시작 전에 "칙" 하는 짧은 잡음(40 ms), 끝나고 짧은 잡음과 낮은 클릭(BFV처럼 무전기를 놓는 소리).
- **가끔 끊김**: 3 % 정도 확률로 30~60 ms 소리가 푹 꺼진다. 거슬리면 끈다.
- **설정 묶음**: 지휘관 = 좁은 대역에 잡음을 조금, 통신병 = 더 좁고 잡음이 많게, 진행자 = 효과 없이 깨끗하게.
- **덕킹**: 음성이 나오는 동안 게임 소리(world 버스)를 −5 dB 낮췄다가(0.15초) 끝나면 0.4초에 걸쳐 되돌린다. 나중에 음악이 들어오면 음악도 같이 낮춘다.
- 지금 오디오 구조는 world 버스 → 리버브·먹먹함 필터 → master → 컴프레서다. 음성 버스는 world를 거치지 않고 master로 바로 간다. 그래서 폭발에 귀가 먹먹해지는 효과(`muffle`)가 무전을 덮지 않는다.
- 재생 직전에 노드를 만들고 끝나면 정리한다. 동시에 1개만 재생하므로 비용은 거의 없다.

| (나중) 빨간 편 지휘관 | **daniel** | bill | 권위 있는 방송인 톤. 파란 편 brian과 결이 달라 편이 구별된다 |

**꼭 먼저 시험할 것**: 이 21개는 영어가 모국어인 목소리다. eleven-v4가 한국어를 읽긴 하지만 **외국인 억양이 섞일 수 있다.** 그래서 본 생성 전에 후보마다 3줄씩 시험해서 들어 보시길 권한다.
- 시험 줄: "거점 브라보 확보." / "증원 병력이 얼마 남지 않았다." / "적이 폭약을 설치했다! 당장 해체하라!"

억양이 거슬리면, 캠페인 C0 때처럼 ElevenLabs 보이스 라이브러리의 **한국어 목소리 ID**를 `voice`에 넣는 방법이 있다. C0에서 윤태섭 목소리를 ID로 썼다(`docs/design/campaign.md` 3장).

**생성 설정 제안**
- 감정 태그를 문장 앞에 붙인다. 평소 보고는 `[calm]` 또는 `[firm]`, 잃었을 때와 위기는 `[urgent]`, 승리는 `[relieved]`. C0에서 쓴 `[tense]`도 된다.
- 안정성(stability)은 중간보다 조금 높게 잡는다. 같은 화자가 100줄 내내 같은 사람처럼 들려야 하기 때문이다.
- 숫자와 글자는 읽는 대로 적는다. 자막은 "거점 B", 생성 입력은 "거점 브라보".
- 만든 뒤에는 C0 때처럼 `elevenlabs/scribe-v2`로 받아쓰기를 돌려 틀린 줄을 찾는다(제가 스크립트로 돌릴 수 있다).

## 8. 파일과 파이프라인 [제안]

- 대사표를 `docs/design/briefing-lines.csv`로 만든다. 열은 큐, 변형 번호, 화자, 감정 태그, 자막(한/영), 생성 입력, 파일 이름이다. 오너가 이 표대로 생성하면 된다.
- 파일 이름은 `<큐>_<번호>.mp3`, 예: `zone.taken.B_1.mp3`. 받은 파일은 `assets-src/voice/ko/`에 둔다(git에서 빠지는 원본 폴더).
- `npm run voice`(새로 만든다)가 할 일:
  - 앞뒤 무음 자르기, 음량 맞추기(loudnorm −18 LUFS), 끝 페이드
  - 모노 24 kHz, 48 kbps mp3로 변환해 `public/assets/voice/ko/`에 저장
  - 대사표와 대조해 빠진 줄과 남는 파일을 알려 주고 `index.json`을 만든다
- 원하면 이 스크립트가 오너의 OpenRouter 키(`assets-src/openrouter.key`)로 생성과 받아쓰기 검사까지 한 번에 할 수도 있다. 오너가 직접 만들겠다고 했으니 기본은 위처럼 가져다 넣는 방식이다.
- **용량**: 한 줄 평균 2.5초 기준 줄당 약 15 KB, 95줄이면 약 1.4 MB다. 게임 시작 때 전부 받지 않고, **그 판의 모드에 쓰는 큐만** 로딩 중에 받는다(보통 30~40줄, 0.5 MB 안팎). 파일이 없는 큐는 띠만 뜨므로, 대사를 일부만 만들어도 게임은 문제없이 돈다.
- 새 오디오는 `sounds.manifest.json`과 같은 방식으로 `voice.manifest.json`에 기록하고, 크레딧에 "Voices: ElevenLabs"를 넣는다.

## 9. 만드는 순서 [제안]

1. **시스템 먼저**(음성 파일 없이): 큐 표, 트리거, 수다 방지 규칙, 크리티컬 메시지 띠, 음성 버스와 무전 효과, 덕킹, 설정 2개. 확인용으로 브라우저 TTS 같은 임시 음성 대신 키 소리와 잡음만 낸다. 봇전에서 1분에 몇 번 뜨는지 재서 규칙을 맞춘다.
2. **대사표 확정**: 오너가 3장 대사를 고친다. 그다음 CSV를 뽑는다.
3. **목소리 시험**: 후보 목소리마다 3줄씩 만들어 들어 보고 고른다(오너).
4. **본 생성과 넣기**: 오너가 생성하고 `npm run voice`로 넣는다. 받아쓰기 검사를 하고, 게임에서 들어 본다.
5. **2단계**: 위협 경보(통신병), 빨간 편 목소리, 영어 음성.
