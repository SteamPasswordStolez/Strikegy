# UI/UX 점검 (2026-10-17)

사장님 요청: "UI/UX가 AI 슬롭이 심하고 BF/CoD의 세련되고 편한 느낌이 안 난다" → 고치기 전에 현재 상태를 점검.
목표(사장님, 2026-10-17): 그래픽·분위기는 **BFV**, 손맛은 기본으로 깔고 간다. UI/UX부터 시작.

점검 방법: 개발 빌드(`npm run dev`), 앱의 브라우저 창, 1280x720, Iron Gate 12v12 봇전. 로컬 게임 서버(`npm run server`)로 멀티 화면.
화면마다 스크린샷을 찍어 보고, `src/styles.css`와 `src/ui/*`를 숫자로 셌다.

중요도: **큼** = 첫인상·매 판 체감, **중간** = 자주 보임, **작음** = 다듬기.

## 1. 요약: 싸 보이는 이유 다섯 가지

1. **디자인 시스템이 없다 (큼).** 화면을 기능마다 따로 만들어 붙였다. `styles.css` 5,362줄에 글자 크기 34종, 색 206종(hex 46 + rgba 160), padding 89종, 그림자 102곳, 그라디언트 43곳. 정해진 단계 없이 그때그때 고른 값이라 화면끼리 미묘하게 다르고, 그게 "기본값/AI가 만든 것" 느낌을 낸다.
2. **글이 너무 많다 (큼).** 게임 설정 한 화면에 213단어. 모드마다 부제, 규칙 목록, 설정 줄마다 설명(`기본 난이도입니다.` 같은 빈 문장 포함), 하단 요약줄이 위 내용을 한 번 더 반복한다. BF/CoD는 그림으로 보여주고 글은 필요할 때만 꺼낸다.
3. **그림이 없다 (큼).** 맵은 위에서 본 도면, 무기는 이름과 막대 4개, 로딩은 로고와 막대뿐. 총(`gunModels.ts`)과 맵이 코드로 다 있는데 메뉴에서 쓰지 않는다. BF/CoD 메뉴는 화면의 절반 이상이 그림(맵 장면, 총 3D, 병사)이다.
4. **글꼴과 크기 (큼).** 웹폰트가 없어서 한글이 맑은 고딕(시스템 글꼴)으로 나온다. 글자 대부분이 9~14px(11px 47곳, 13px 36곳, 12px 32곳)이고 화면 크기에 따라 커지지 않아서, 1440p·4K에서는 더 작아진다.
5. **소리와 손맛이 없다 (큼).** 메뉴에 마우스를 올리거나 클릭하거나 화면이 넘어갈 때 아무 소리도 나지 않는다(UI 효과음 없음). CoD 메뉴가 고급스럽게 느껴지는 이유의 절반이 이것이다.

여기에 **기호가 들쭉날쭉**하다(작음~중간): 이모지 💬 🔒 🖥 📱, 유니코드 ◆ ▣ ❚ ▲ ◎ ✚ ⌂ ◀ ▶, 직접 그린 선 아이콘이 섞여 있다.

## 2. 동선 (사이트를 열고 싸우기까지)

| 단계 | 지금 |
|---|---|
| 첫 방문 | 이름 창이 먼저 막는다 (입력 + 확인) |
| 메인 메뉴 → 플레이 | 1클릭 |
| 게임 설정 → 게임 시작 | 1클릭 |
| 로딩 | **약 23초** (개발 빌드, Iron Gate, 플레이 클릭부터 배치 화면까지 24.6초. 배포 빌드는 더 빠를 수 있다) |
| 배치 화면 → 배치 | 1클릭 (+ 마우스 잡기 클릭) |
| 배치 → 첫 교전 | 재지 못함 (아래 "못 본 것") |

- 클릭 수는 적어서 괜찮다. 문제는 **로딩 23초 동안 볼 것이 없다**는 것: 로고, 막대, "병사 준비 중" 한 줄뿐. 맵 이름도, 모드도, 팁도 없다.
- 첫 방문의 이름 창은 바로 플레이하는 흐름을 막는다. 손님 이름을 자동으로 주고 나중에 바꾸게 하는 편이 웹게임에 맞다.
- 한 번 매치를 하면 탭이 그 매치를 기억해서, 새로고침하거나 주소를 직접 바꿔 쳐도 같은 매치로 다시 들어간다(`core/session.ts`). 의도된 기능이지만 메뉴로 돌아가는 길이 일시정지 → 나가기 하나뿐이다.

## 3. 화면별

### 메인 메뉴 (`Lobby.ts`)
- 지금: 왼쪽에 기울인 로고, "봇 전장" 부제, 메뉴 7개(플레이 / 멀티플레이 / 사격장 / 튜토리얼 / 조작법 / 설정 / 크레딧)가 같은 크기로 나란히, 그 아래 설명 한 줄, 오른쪽 위 이름. 뒤에는 녹화한 전투 영상.
- **큼**: 뒤 영상이 게임의 가장 덜 다듬어진 모습(밋밋한 상자형 집, 평평한 색)을 크게 보여준다. 가장 오래 보는 화면이 첫인상을 깎는다.
- **중간**: 위계가 없다. "플레이"와 "크레딧"이 같은 무게. CoD/BF는 플레이(또는 빠른 시작)가 압도적으로 크고, 설정은 구석의 아이콘이다. 조작법·튜토리얼·크레딧은 맨 위 단계에 있을 필요가 없다.
- **작음**: 위아래 키가 끝에서 반대쪽으로 넘어간다(플레이에서 ↑ = 크레딧). 항목마다 설명 줄.

### 게임 설정 / 방 만들기 (`MatchSetup.ts`, 공용)
- 지금: 세 칸. 왼쪽은 스크롤되는 모드 13개(각각 부제), 가운데는 맵 도면 + 이름 + 소개 + 썸네일 5개, 오른쪽은 모드 이름·소개·규칙 목록·설정(줄마다 설명)·요약줄·시작 버튼.
- **큼**: 글 213단어. 네 덩어리가 모두 같은 무게라 시선이 갈 곳이 없다.
- **큼**: 맵이 도면으로 나온다. 맵을 고를 때는 그 맵의 분위기(장면 사진)를 보여줘야 한다.
- **중간**: 모드 이름은 영어(Zone, Frontline, Rush...), 맵 이름과 나머지는 한국어로 섞여 있다.
- **중간**: 방 만들기에서는 720p 화면에서 '방 만들기' 버튼이 화면 밖(아래 905px)으로 밀려나 스크롤해야 보인다(Enter로는 된다).
- **작음**: 요약줄("Zone · 철문 주둔지 · 12 vs 12 · 봇 보통")이 바로 위 내용을 반복한다.

### 설정 (`SettingsPanel.ts`)
- 지금: 조작 4줄, 키 설정, 화면 5줄, 소리·언어 2줄. 오른쪽 절반이 비어 있다.
- **중간**: BF/CoD에 비해 항목이 적다. 그래픽은 프리셋 하나뿐(그림자, AO, 시야 거리, 안티에일리어싱, 모션 블러 개별 설정 없음), 소리는 전체 음량 하나(효과음·음악·음성·UI 따로 없음), 조준점 꾸미기, HUD 크기, 색약 모드, 조준 시 시야각, 배율별 감도가 없다.

## 4. 고치는 순서 (제안)

1. **디자인 시스템.** 글꼴, 크기 단계(예: 6단계), 간격 단계, 색 토큰(지금 206종 → 20종 안팎), 버튼·목록·탭·슬라이더·칩 부품, 아이콘 한 세트(이모지와 유니코드 기호는 없앤다), 움직임 규칙(0.15~0.25초), UI 효과음 세트, 화면 크기에 따른 UI 배율. **하나의 견본 페이지로 만들어 사장님 승인을 받은 뒤** 화면에 적용한다.
2. **메인 메뉴 + 로딩.** 첫인상. 플레이를 크게, 나머지는 줄인다. 뒤 배경은 다듬은 맵 장면으로 바꾸고, 로딩에 맵 장면·이름·모드·팁을 넣는다.
3. **게임 설정 / 방 만들기.** 글을 줄이고(규칙은 접어 두고 필요할 때 펼치기), 맵은 장면 사진으로, 모드 이름은 한국어로 통일한다.
4. **배치 + 무기 선택.** 맵을 화면 가득, 총은 3D 모델(이미 있는 `buildGun`)로 보여준다.
5. **결과 화면.** 내 성적 요약, 다음 판으로 이어지는 흐름.
6. **일시정지 / 점수판 / 설정**(항목 늘리기) / 멀티(초대 링크, 빠른 참가).
7. **HUD**는 마지막에, 손맛 점검(맞힘·처치 피드백)과 함께 BFV처럼 비운다.

### 받아야 할 것 (다운로드 승인 필요, 목록은 따로 드림)
- 한글 글꼴: **Pretendard**(SIL OFL, 무료, 서브셋하면 수백 KB) 유력. 숫자·영문용 콘덴스드 글꼴 하나(OFL).
- UI 효과음: CC0 세트(마우스 올리기, 클릭, 뒤로, 화면 넘김, 확인) 몇 개.
- 아이콘: 직접 그려도 되고, MIT/CC0 아이콘 세트에서 골라도 된다.

## 5. 이번에 못 본 것
- 터치(폰) 화면, 1440p·4K 화면.
- 배치 후 첫 교전까지 걸리는 시간, 맞힘·처치 피드백(손맛 점검 때 본다).
- 실제 마우스 잡기(pointer lock)가 있을 때의 Esc 흐름. 앱 브라우저 창에서는 Esc로 일시정지가 열리지 않아 코드로 열었다.
- 두 사람이 함께 들어간 대기실.
- 배포 빌드의 로딩 시간(개발 빌드로만 쟀다).
