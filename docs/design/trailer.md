# 출시 트레일러 설계 [제안]

오너 요청(2026-10-31): 여느 FPS처럼 출시 트레일러를 만든다. 콜 오브 듀티 모던 워페어 4 출시 트레일러 같은 느낌. 음악은 **Engaging 하나만** 쓴다 (처음엔 2분쯤으로 줄인 편집본이었으나, 오너가 같은 날 **원곡 그대로(2분 17초)** 로 정했다). 장면 전환은 음악의 파형·분위기·묵직한 타격에 맞춘다. 2차 요청(같은 날): **실제 플레이 1인칭 화면을 넣을 것**(봇을 3인칭으로 찍은 것이 아니라), **처음 4–5초는 게임사 로고와 이름만**, **이야기가 분명할 것**. 3차 요청(같은 날): 대사를 많이, 게임사 GlitchedSpell(로고는 Claude가), 영어 대사 + 한국어 자막, 출시 당일 공개, 게임 UI는 보이면 안 됨(숨김 단축키), 1인칭 촬영은 오너가 좌표를 받아 직접.

[제안]은 오너가 아직 정하지 않은 것이다.

**만드는 법은 `docs/design/trailer-production.md`**(로컬 세션용 제작 안내서)에 있다. 컷 시간과 대사의 기계용 원본은 `scripts/trailer/data/shots.json` / `lines.json`이고, 이 문서의 표와 늘 같아야 한다.

## 1. 참고: 모던 워페어 트레일러 문법

모던 워페어 4(2026-10-23 출시)는 공개, 도쿄 게임쇼 캠페인, 선전물 형식 트레일러가 확인된다. 출시 트레일러는 컷 단위로 분해한 자료를 찾지 못했고, Claude는 영상을 볼 수 없다. 그래서 MW 시리즈 트레일러에 공통으로 쓰이는 문법을 가져온다.

- **조용한 냉기로 시작한다.** 어두운 화면과 무전 잡음 위에 지휘관의 담담한 독백이 깔리고, 클로즈업이 느리게 움직인다.
- **검은 화면에 흰 글씨 한두 단어**를 넣는다. 화면 사이의 "숨"이자 문장이다.
- **음악의 타격 = 컷.** 큰 타격 하나에 큰 그림 하나를 둔다(포격, 일제사격, 폭발).
- **한 번 완전히 멈춘다.** 정적 속 대사 한 마디 뒤에 모든 것이 동시에 터진다.
- **가장 빠른 몽타주 → 로고**를 마지막 큰 타격에 맞추고, 끝 화면을 붙인다.

블루/레드는 진영 이름 없이 쓰고 호출부호만 쓴다. 보류 중인 캠페인 설정과 부딪히지 않는다.

## 2. 음악 분석 (Engaging)

`public/music/engaging.mp3`, 2분 17초, 스테레오. ffmpeg로 풀어 numpy / scipy로 분석했다. 쓴 지표는 0.5초·1초 단위 음량, 저/중/고역 에너지, 스펙트럼 무게중심, 스펙트럴 플럭스, 저역(30–150 Hz) 온셋, 박자 자기상관, 그리고 앞 1초보다 튀어나오는 정도(대비)다. 오너는 풀버전이 3분쯤이라고 했지만 게임에 든 파일이 원본 전체이고 2분 17초다(빌드 스크립트는 자르지 않는다).

- **템포:** 105 BPM, 한 마디 2.286초. 첫 다운비트는 0.12초. 140 BPM으로도 읽히는데, 점8분(0.43초) 타격이 많기 때문이다.
- **저음 킥:** 1/4박 단위로 거의 내내 깔려 있다. 그래서 "묵직한 한 방"은 저역 세기만이 아니라 **앞 1초보다 얼마나 튀어나오는지(대비)**로 골랐다.

## 3. 이야기: "부름" [제안]

### 오너가 정한 것 (2026-10-31)

| 항목 | 결정 |
|---|---|
| 게임사 | **GlitchedSpell**. 로고는 Claude가 만든다: `public/brand/glitchedspell-*.svg`, 생성기 `scripts/brand/glitchedspell.py` |
| 대사 | **영어 대사 + 한국어 자막.** 대사만 영어이고, 화면 글자(카드, 진급 그래픽, 끝 화면)는 **모두 한국어** (오프닝의 "PRESENTS"와 로고만 영어) |
| 공개 시점 | **출시 당일** 공개 → 끝 화면은 출시일이 아니라 "지금 플레이" |
| 제작 | **트레일러 영상은 전부 오너 PC의 로컬 세션에서 만든다** (촬영, 녹음, 편집). 클라우드 세션은 계획과 도구까지 |
| 화면 | **게임 UI는 보이면 안 된다** → 촬영 모드 단축키 **F2** (아래 5장) |
| 촬영 | 1인칭 실플레이는 오너가 직접 찍는다. Claude는 맵과 좌표를 준다 (6장) |
| 인물 이름 | 붙여도 안 붙여도 좋다 → 고유 이름 없이 호칭과 호출부호만 쓴다 |

**한 줄:** 첫 실전에 나선 무전병 이병("kid")의 눈으로 본다. 분대장("Sarge")의 무전 한 통에 기갑·항공·해군이 답하고, 분대장이 쓰러지자 무전기는 이병에게 넘어간다. 정적 속에서 "…Now."라고 말하고 돌격을 이끄는 것은 그 이병이다. 마지막에 일병으로 진급한다.

### 대사 (영어, 한국어 자막) [제안]

배치 원칙:
- **음악이 조용한 곳에는 대화와 독백:** 인트로, 브레이크다운, 숨 고르기, 끝 화면.
- **드롭에서는 백비트 사이에 1초 안팎의 외침과 무전 호출.**
- **말이 겹치지 않는 곳:** 가장 센 타격(38.60 / 66.42 / 70.89 / 91.17 / 128.15)과 완전 무음(69.90).
- **음악 덕킹:** 말하는 동안 음악을 3–4 dB 낮추고, 무전에는 게임의 무전 체인을 입힌다.
- **길이:** 영어 초당 약 2.8단어로 어림했다. 녹음 뒤 실제 길이에 맞춰 0.1–0.3초씩 조정한다.
- **자막:** 화면 아래 가운데, 말과 같은 시간에 표시한다.

말투 표시: 근접 / 무전 / 속삭임 / 외침 / 슬로(슬로모션 속 먹먹한 소리).

## 4. 장면표 (원곡 시간, 30 fps 프레임)

컷은 표의 시간 **정각**에 건다. 프레임 = 시간 × 30, 반올림. **모든 컷은 게임 UI 없이 찍는다**(촬영 모드 F2).

**종류 표기:**
- **FP** = 실제 플레이 1인칭(오너가 직접 플레이). 총과 손만 보인다.
- **FP·탑승** = 차량에 탄 상태의 실제 1인칭(전차 포수, 조종석, 대공포, 잠망경 위치). UI가 없으니 조준경 그림 없이 그 자리의 시야만 나온다.
- **FP·연출** = 대사 장면의 1인칭. 분대원 배치처럼 장면 세팅이 필요하다.
- **CINE** = 3인칭 와이드 연출. 규모를 보여 줄 때만 쓴다.

오프닝을 뺀 132초 가운데 실제 플레이(FP / FP·탑승)가 약 57 %(75초쯤), FP·연출 약 14 %, CINE 약 14 %, 카드·검은 화면·타이틀 약 16 %다(장면표에서 계산).

## 4. 장면표 (원곡 시간, 30 fps 프레임)

컷은 표의 시간 **정각**에 건다. 프레임 = 시간 × 30, 반올림. **모든 컷은 게임 UI 없이 찍는다**(촬영 모드 F2).

**종류 표기:**
- **FP** = 실제 플레이 1인칭(오너가 직접 플레이). 총과 손만 보인다.
- **FP·탑승** = 차량에 탄 상태의 실제 1인칭(전차 포수, 조종석, 대공포, 잠망경 위치). UI가 없으니 조준경 그림 없이 그 자리의 시야만 나온다.

- **CINE** = 3인칭 와이드 연출. 규모를 보여 줄 때만 쓴다.

## 5. 촬영 도구 (만들어 둠, 2026-10-31)

- **F2 (촬영 모드):** 매치 안에서 누르면 게임 UI가 모두 사라지고 한 번 더 누르면 돌아온다. 키 설정에서 다른 기능에 쓸 수 없게 예약했다.
  - 사라지는 것: HUD 전부(미니맵, 크로스헤어, 탄약, 킬피드, 알림, 튜토리얼 카드, 진급 알림, 채팅, 차량 조준경·조종석 그림, 터치 버튼)와 세계 속 표시(거점 바닥 고리와 문자, 아군 표식과 소생 십자, 항공기 표식, 지원 호출 조준 고리, 보급소 아이콘, 건설 모드 밖의 청사진).
  - 남는 것: 1인칭 총과 손, 깃대와 깃발, 저격 스코프의 렌즈 화면(광학이라 그림의 일부로 봄).
  - 확인: 헤드리스 브라우저에서 Iron Gate B 거점 근처를 F2 전후로 찍어 비교했다.
- **`?nohud=1`:** 처음부터 촬영 모드로 시작한다.
- **`?at=x,z,방위` 또는 `?at=x,y,z,방위` (싱글 매치만):** 배치할 때마다 그 자리에 선다.
  - 방위는 북쪽(-z) 기준 시계방향 도(0 북, 90 동, 180 남, 270 서)다.
  - y를 주면 그 높이 바로 아래 바닥(건물 층)에, 없으면 땅이나 지붕 위에 선다.
  - 이 옵션을 쓴 판은 진급 기록에 반영되지 않는다.
- **F3:** 화면 위 줄에 현재 위치 x, y, z와 바라보는 방위(°)가 나온다. 좋은 자리를 찾으면 그 숫자를 `?at`에 넣으면 된다.
- **장면 세팅이 필요한 컷:** 분대원이 정해진 자리에 있어야 하는 FP·연출 컷과 CINE 컷은 아직 도구가 없다. 개발 전용 장면 세팅(봇 위치·행동 고정, 슬로모션)을 따로 만들어야 한다.
