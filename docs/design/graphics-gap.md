# 왜 BF·CoD만큼 안 보이나 (2026-10-31 분석)

오너 질문: "아직도 왜 배틀필드나 콜오브듀티급의 그래픽 수준에 못 따라가는지 원인을 파악하고, 연산이 과도하지 않은 선에서 최대한 개선."
측정·확인은 이 PC의 GTX 1660 Ti(헤드리스 Edge, ANGLE D3D11), 1152x648 high.

## 원인 (영향이 큰 순서)

1. **움직이는 것에 그림자가 없었다.** 병사·차량·수류탄은 그림자를 전혀 드리우지 않았다(정적 그림자 지도 하나라 움직이는 그림자를 넣을 수 없었음). 발밑의 원형 그늘만 있어서 인물이 땅에서 떠 보인다. BF·CoD는 카메라 근처를 촘촘한 그림자 단계(cascade)로 매 프레임 그린다. → **고침**(근접 그림자).
2. **그림자가 거칠고 옅었다.** 맵 전체를 3072 텍셀 한 장으로 덮어 Iron Gate 약 11 cm, 재의 섬 약 60 cm 단위. 그리고 하늘 반사광(IBL 0.85)과 반구광이 햇빛(2.4)에 비해 강해서 그림자가 푸르고 옅었다 — 명암이 약하면 화면이 평평해 보이는 가장 큰 이유. → **고침**(근접 그림자 2.5 cm, 낮·열대 프로필의 햇빛 ↑ 하늘광 ↓).
3. **간접광(빛 번짐)이 없다.** 햇빛이 바닥·벽에 튀어 그늘을 밝히는 효과가 없고, 그늘은 하늘색 IBL 하나로만 채워진다. AO는 high에서만, 반해상도 GTAO. → 남음(라이트 프로브/베이크가 필요; 비용 큼).
4. **재질이 깨끗하고 반복된다.** 절차 텍스처 512, 스캔 텍스처 1K가 맵 전체에 같은 크기로 반복; 얼룩·빗물 자국·깨짐 같은 데칼이 없다(거시 변화 노이즈와 건물 아래쪽 grime만 있음). → 남음(데칼 시스템, 텍스처 세트 추가 — 다운로드는 승인 필요).
5. **형태가 각지다.** 맵 상자·건물·차량이 상자 조합. 지형지물 리워크로 많이 나아졌고 이번에 건물 외벽(창틀·상인방·띠·처마·기단)과 승용차를 다시 만들었다. → 진행 중.
6. **안티에일리어싱이 FXAA뿐.** TAA가 없어 가는 물체·먼 모서리가 반짝이고 계단진다. → 남음(TAA는 지터·속도 버퍼가 필요, 큰 작업).
7. **대기감이 약하다.** 균일한 지수 안개, 높이 안개·빛줄기 없음. → 남음(높이 안개는 싸다: 다음 후보).

## 이번에 한 것

  - 비용(같은 페이지에서 4프레임씩 켜고 끔, Iron Gate 거점 5곳): 처음(근처 전부 매 프레임) GPU +0.39 ms·CPU +0.28 ms/시점 → 움직이는 것만 + 격 프레임: **GPU +0.14 ms, CPU +0.04 ms**.
