# 손맛 점검 (2026-10-18)

오너 요청: "BFV와 CoD MW(2019)를 참고해, 특히 후자를 더 많이" 사격의 손맛을 점검.
이 문서는 **지금 코드가 어떻게 되어 있는지**(수치, 파일), **MW2019 / BFV는 어떻게 하는지**, **무엇을 어떤 순서로 고칠지**를 정리한다. 고치는 일은 오너가 순서와 [제안] 수치를 승인한 뒤 시작한다.

- 근거: 코드와 수치는 이 저장소에서 직접 읽고 계산했다(TTK 표는 `weaponData.ts`로 계산).
- MW2019 / BFV 수치는 커뮤니티 측정값과 알려진 설계를 바탕으로 한 **대략치**다. 게임을 직접 재 본 값이 아니다.
- 클라우드 세션이라 실제 느낌(소리, 화면 반동, 프레임)은 확인하지 못했다. 각 단계는 오너가 직접 쏴 보고 판단해야 한다.

## 3. 발견 사항 (손맛에 미치는 영향 순)

### A. 쏠 때의 반응 (가장 큼)

1. **총 모델 반동이 모든 총에 같다.** `ViewModel.onFire` (`src/weapons/ViewModel.ts:443`)
   - 한 발에 뒤로 0.04 m, 회전 0.07 rad(정조준 0.025 / 0.03), 최대 0.08 / 0.2.
   - 저격총도 MP7과 똑같이 튄다. 무기 데이터의 `recoil`은 조준점만 움직이고 손에 든 총에는 영향이 없다.
   - MW2019의 손맛은 대부분 여기서 나온다. 총이 어깨로 밀려 들어오고, 위로 들리고, 좌우로 비틀리고, 화면이 살짝 흔들린다. 그런데 실제 조준이 움직이는 양은 보이는 것보다 작다.
2. **내 사격에는 화면 흔들림이 없다.** `Game.shake`는 차량 포, 근접, 폭발에만 쓰인다.
   - MW는 조준과 상관없는 화면 반동(카메라 펀치, 살짝 기울기)을 따로 둬서 "세게 쏜다"는 느낌을 준다.
3. **반동이 저절로 돌아온다.** `RECOIL_RECOVERY = 6`, 0.12 s 쉬면 시작 (`WeaponController.ts:247-252`).
   - 한 번 끊어 쏘면 조준이 원래 자리로 미끄러져 돌아간다. 끌어내리는 맛, 제어하는 맛이 없다.
   - MW2019는 반동이 거의 돌아오지 않는다. 손으로 끌어내린다.
4. **반동 패턴을 배울 수 없다.** `recoilKick` (`recoil.ts`)
   - 좌우 흔들림이 연사마다 무작위 위상의 사인파다. 같은 총이라도 연사마다 다른 쪽으로 흐른다.
   - MW는 총마다 경향(예: 위로 갔다가 오른쪽)이 있고 무작위는 작다. 그래서 숙련이 손에 붙는다.
5. **정조준해도 총알이 조준점에서 벗어난다.**
   - `spreadAds` AR 0.25°, SMG 0.45°, LMG 0.5°에 연사 퍼짐(`bloom`, 최대 3°의 절반)이 더해진다.
   - 100 m에서 AR 첫 발이 조준점에서 최대 44 cm 벗어나고, 연사하면 최대 약 3 m까지 벗어난다.
   - MW는 정조준하면 총알이 조준점으로 간다. 빗나가는 이유는 눈에 보이는 반동뿐이라 "보이는 대로 맞는다". 오너가 MW를 더 참고하라고 했으니 가장 중요한 차이 중 하나다.
   - 지향사격(hip)은 AR 1.7°로 꽤 정확하다. 10 m에서 반경 30 cm라 근거리에서는 정조준할 이유가 적다. MW는 지향사격이 더 넓다.

### B. 소리

1. **총소리 녹음이 클래스당 하나다.** 7개로 23정, `sounds.manifest.json`의 `gun_*`.
   - 돌격소총 네 정이 같은 소리다. LMG는 AK-47 녹음을 쓴다. 높낮이는 ±3 %만 바뀐다.
   - 이미 승인된 CC0 라이브러리(The Free Firearm Sound Library)에 다른 총 녹음도 들어 있다.
2. **명중 / 헤드샷 / 킬 소리가 합성 전자음이다.** `AudioSystem.hit` (`AudioSystem.ts:1087`)
   - 일반 명중은 사각파 1200 Hz 40 ms, 헤드샷은 삼각파 1800 Hz, 킬은 660 → 990 Hz 두 음이다. 메뉴 차임처럼 들린다.
   - MW는 짧고 마른 '틱'에 둔탁한 몸 맞는 소리를 섞고, 헤드샷과 킬은 따로 더 무거운 소리를 낸다.
3. **총알이 내 옆을 지나가는 소리가 없다.**
   - 봇은 근접탄으로 제압을 받는다(`nearMiss`). 하지만 플레이어 쪽에는 크랙(초음속 '딱')도 휘익 소리도 없다.
   - MW와 BFV 모두 "총에 맞고 있다"는 느낌의 핵심이다.
4. **울림이 주변을 따르지 않는다.** 꼬리(`tail`) 길이가 클래스마다 고정이다.
   - 실내든, 골목이든, 들판이든 같다. MW2019 사운드의 대표적인 장점이 실내 / 실외 / 건물 사이 반사다.
5. **맞힌 몸에서 나는 소리가 없다.** 총알이 사람에 맞으면 명중음만 나고 육중한 타격음이 없다.
6. **탄창 끝 경고음이 없다.** MW는 마지막 몇 발에 기계음이 바뀐다. 탄피 소리는 있다.

### C. 맞혔을 때 보이는 것

1. **히트마커가 켜졌다 꺼질 뿐이다.** `HUD.showHit`, `hud.css .hitmarker`
   - 0.15 s(킬 0.35 s) 동안 그대로 떠 있다가 사라진다. 튀어나오거나 사라지는 동작이 없고 데미지 크기와도 상관없다.
2. **맞은 적의 반응이 약하다.** `SoldierModel.onHit` / 사망
   - 상체가 0.2 rad 움찔한다. 사망은 0.55 s 동안 옆으로 넘어지는 동작 하나(좌우만 무작위)다. `bodyHit` 입자는 4개다.
   - 달리다 맞아도, 뒤에서 맞아도 똑같이 넘어진다.
3. **예광탄이 레이저처럼 보인다.** `Effects.addTracer`
   - 내 총은 매 발 1픽셀 GL 선이 순식간에 전체 길이로 나타나 사라진다.
   - MW에서 내 총의 예광탄은 드물고, 예광탄은 날아가는 짧은 빛줄기다.

### D. 맞을 때

1. **조준이 튀지 않는다(플린치 없음).** 피해 25면 무작위 흔들림이 0.01 rad 정도다.
   - MW는 맞으면 조준이 위로 튀어서 "먼저 맞은 쪽이 불리"하다는 긴장이 생긴다.
2. 피해 방향 표시와 붉은 비네트는 있다. 괜찮다.

### E. 무게감 (다루는 느낌)

1. **질주 후 사격이 0 ms다.** `Soldier.step` (`src/sim/Soldier.ts:241`)
   - 방아쇠를 당기는 틱에 질주가 끝나고 바로 발사된다. 화면의 총은 아직 질주 자세로 내려가 있다.
   - MW는 클래스마다 질주 해제 시간(대략 SMG 150 ms ~ LMG 350 ms+)이 있고, 총을 들어 올리는 동작이 보인다.
2. **정조준 시간이 짧다.** 128-297 ms. MW는 대략 AR 250-300, SMG 200 안팎, LMG 400-600, 저격 500-700 ms다.
   - 특히 LMG와 저격총이 가볍게 느껴진다.
   - 정조준이 들어갈 때 총이 자리 잡는 흔들림(settle)도 없다.
3. **총 꺼내기가 모두 0.35 s다.** `DRAW_TIME`: 권총과 LMG가 같다.
4. **장전 시간이 총마다 하나다.** 탄이 남았을 때(전술 장전)와 다 쐈을 때(노리쇠 당김)의 차이가 없다. 우선순위는 낮다.

### F. 거리 개성 (밸런스 쪽)

- `damageAtDistance`: 모든 총이 사거리 40 %까지 최대 데미지이고, 사거리에서 60 %가 된다.
- SMG가 60 m, AR이 100 m까지 근거리와 같은 탄 수로 죽인다. 그래서 "근거리에선 SMG, 중거리에선 AR"이라는 선택이 약하다.
- MW는 SMG 데미지가 15-25 m부터, AR은 35-50 m부터 단계적으로 떨어진다.

## 4. 고칠 순서 (제안)

MW2019 비중을 높게, 체감이 큰 것부터 했다.
각 단계는 서버와 봇이 같은 수치를 쓴다(`weaponData.ts`는 공유). 그래서 데미지나 정확도를 바꾸는 단계는 `npm run bots:pace`로 교전 페이스가 무너지지 않는지 확인한다.

### 1단계: 쏠 때의 반응 (보이는 반동)

- 총마다 **총 모델 반동 프로필**을 둔다: 뒤로 밀림, 들림, 비틀림, 좌우 무작위, 복귀 속도.
  - 무기 데이터에 `kick` 항목을 추가하고 클래스 기본값 + 총별 덮어쓰기로 한다. 저격총과 산탄총은 크고 느리게, SMG는 작고 빠르게.
- **조준과 상관없는 화면 반동**을 둔다: 한 발마다 작은 카메라 펀치와 기울기. 조준점에는 들어가지 않는다.
- **정조준은 조준점으로**: 정조준 시 퍼짐 → 0에 가깝게, 연사 퍼짐도 정조준 중엔 적용 안 함. 정확도는 보이는 반동이 대신 맡는다.
- **반동 복귀 제거 또는 축소**, 그리고 **총마다 익힐 수 있는 패턴**(총별 고정 경향 + 작은 무작위).
- 확인: 사격장에서 총별 연사 탄착(벽에 찍힌 자국)과 화면 녹화. 오너가 직접 쏴 보기.

### 2단계: 소리

- **명중 / 헤드샷 / 킬 소리 새로 만들기**: 짧은 '틱' + 몸 맞는 둔탁음, 헤드샷은 따로, 킬은 무거운 한 방.
  - 우선 코드로 합성하고, 필요하면 CC0 녹음을 쓴다(그 경우 다운로드 승인 필요).
- **총알 스치는 소리**: 적탄이 플레이어 근처(약 3 m 이내)를 지나가면 크랙 / 휘익. 거리와 총 종류에 따라 다르게.
  - 봇의 `nearMiss`와 같은 판정을 플레이어에게도 적용한다. 멀티에서는 서버 탄도 이벤트를 쓴다.
- **주변에 따른 울림**: 머리 위(천장)와 주변 벽까지의 거리를 몇 개의 레이로 재서 실내 / 골목 / 들판을 고르고, 짧은 반사와 긴 꼬리를 바꾼다.
- **탄창 끝 경고음**: 마지막 몇 발에 다른 기계음.
- **총별 녹음**: 이미 승인된 Free Firearm Sound Library에서 총마다 다른 녹음을 고른다.
  - 다시 받아야 하므로 목록, 크기, 라이선스를 먼저 보여 드리고 승인을 받는다.
  - 소리 파일 합계 제한(≲2.3 MB)을 넘을 수 있어 그 기준도 함께 정해야 한다.

### 3단계: 무게감

- **질주 후 사격 지연**과 총을 들어 올리는 동작.
- **정조준 시간**을 MW 쪽으로 늘리고, 들어갈 때 총이 자리 잡는 흔들림을 넣는다.
- **총 꺼내기 시간**을 클래스마다 다르게.

[제안] 수치 (MW보다 조금 빠르게. 모바일과 간소화 모드 사용자를 고려):

| 클래스 | 질주 후 사격 | 정조준 (지금 → 제안) | 꺼내기 |
|---|---|---|---|
| 권총 | 110 ms | 128 → 150 ms | 0.25 s |
| SMG | 150 ms | 145 → 190 ms | 0.30 s |
| AR | 200 ms | 160-210 → 220-260 ms | 0.40 s |
| SG | 200 ms | 187 → 230 ms | 0.40 s |
| DMR | 250 ms | 230-260 → 280-320 ms | 0.45 s |
| LMG | 350 ms | 220-272 → 330-400 ms | 0.60 s |
| SR | 380 ms | 250-297 → 380-430 ms | 0.55 s |

### 4단계: 맞힐 때 / 맞을 때 보이는 것

- **히트마커**: 튀어나왔다 사라지는 동작, 데미지에 따라 크기, 킬은 빨강으로 더 크게(지금도 빨강).
- **플린치**: 맞으면 조준이 위로 살짝 튄다(데미지 비례, 정조준 중엔 조금 덜).
- **적의 반응**: 움찔을 크게, 맞은 쪽으로. 피 튀는 입자를 늘린다.
  - 사망 동작은 맞은 방향과 달리던 속도에 따라 여러 개로 늘린다. 래그돌은 큰 작업이라 나중에 따로.
- **예광탄**: 날아가는 짧은 빛줄기(화면을 향한 띠)로 바꾸고, 내 총은 몇 발에 한 번만 보이게.

### 5단계: 거리 개성

- 거리별 데미지를 클래스마다 단계로 바꾼다. 근거리 TTK는 지금 그대로 둔다.

[제안]:

| 클래스 | 최대 데미지 거리 | 이후 |
|---|---|---|
| SMG | 20 m | 45 m에서 75 %, 그 뒤 65 % |
| AR | 40 m | 80 m에서 80 % |
| LMG | 45 m | 90 m에서 80 % |
| DMR / SR | 감소 없음 | 헤드샷 배율 유지 |

- 팔다리 배율은 0.85 → 0.95로 올린다(MW식: 사지에 맞아도 탄 수가 잘 안 늘어남).
- 확인: TTK 표를 다시 계산하고 `bots:pace` 전후 비교.

### 하지 않을 것 (지금은)

- **탄도(총알 비행시간, 낙차)**: MW2019와 BFV 모두 있다. 하지만 이 게임의 교전 거리(중앙값 30-55 m)에서는 비행시간이 50 ms 안팎이다.
  - 서버의 지연 보상 판정이 즉발(hitscan) 기준이라 바꾸는 비용이 크다. 저격총만 나중에 검토한다.
- **전술 질주, 거치(mount), 넘어가기(mantle)**: MW의 이동 기능이지만 손맛 점검 범위 밖이다. 따로 정한다.
